# **App Name**: Controle de Vencimentos Marafarma

## Core Features:

- Cadastro de Produtos: Página de cadastro de produtos com campos para código, nome, quantidade, categoria, lote e data de validade. O foco começa no campo de código, percorre os campos e retorna ao código após salvar.
- Integração de Catálogo: Integração com banco de dados de catálogo: preenche automaticamente o nome e a categoria do produto com base no código do produto. Adiciona novos produtos ao catálogo durante o cadastro do produto.
- Painel de Vencimentos: Painel resumindo as datas de validade dentro de 30, 60 e 90 dias, com detalhes para cada intervalo.
- Relatório de Vencimentos: Página de relatório para filtrar por período e mês/ano, e relatórios personalizados para XLS.
- Configurações Avançadas: Página de configurações avançadas, incluindo importação/exportação de banco de dados/catálogo para XLS, personalização da tela inicial e temas claro/escuro.

## Style Guidelines:

- Cor primária: Azul suave (#64B5F6) para evocar uma sensação de confiança e confiabilidade.
- Cor de fundo: Cinza claro (#F0F4F8) para uma aparência limpa e profissional.
- Cor de destaque: Um verde suave (#81C784) para destacar sutilmente ações e status importantes, inspirado no conceito de 'frescor' e pontualidade das informações em um contexto médico.
- Fonte do corpo e do título: 'PT Sans' (sans-serif) para oferecer legibilidade.
- Use ícones claros e funcionais representando categorias de produtos, intervalos de validade e configurações, garantindo que sejam projetados como um formato de gráficos vetoriais para que sejam facilmente dimensionáveis. Considere também o uso de glifos de bibliotecas de ícones estabelecidas que podem ser reutilizados entre projetos.
- Layout limpo e bem organizado, com separação clara de seções e dados. Use um sistema de grade para manter a consistência.
- Transições e animações sutis para uma experiência de usuário suave e responsiva. Considere micro-interações nos cliques de botões e atualizações de dados.
